# 风险评估系统输出字段说明文档

> **更新日期**: 2026-08-07  
> **交付物**: `{stock_code}_risk_report.json`（单只股票风险报告）

---

## 一、文件概述

本 JSON 文件由 `riskSystem.py` 风险评估系统针对**单只股票**生成，包含四个核心部分：

- **执行层**：最终风控指令（等级、处置动作）
- **研究层**：归因明细（AI/历史/财务三方输入与冲突检测）
- **复核层**：自动复核的证据链与裁决结果
- **RAG 摘要层**：自然语言摘要


---

### 3.7 【新增】RAG 摘要字段（`rag_summary`）

本字段是**专为检索增强生成（RAG）系统设计的自然语言文本**，将结构化的风险数据转化为语义连贯、人类可读的段落。

| 字段 | 示例值（节选） | 说明 |
| :--- | :--- | :--- |
| `rag_summary` | `"美的集团(000333)在2026-08-07的风险评估为Ⅳ级风险。主要风险来源是历史直觉。该股票历史年化波动率高达29.34%，历史最大回撤达到60.52%，两项指标均触发了硬阈值极端红线。..."` | 一段 150~300 字的自然语言摘要，涵盖：<br>• 最终等级与处置建议<br>• 主导风险来源<br>• 历史/财务关键指标<br>• AI 评分与冲突说明<br>• 自动复核的归因结论 |

**下游 RAG 系统使用方式**：

| 组件 | 使用方式 |
| :--- | :--- |
| **向量库（索引层）** | 对 `rag_summary` 字段进行 Embedding（向量化），用于语义检索 |
| **结构化过滤（元数据层）** | 将 `final_level`、`has_conflict`、`dominant_source` 作为元数据，支持过滤查询 |
| **LLM 生成（提示词层）** | 检索命中后，将 `rag_summary` 内容拼入 Prompt 的“参考上下文”中，供 LLM 生成汇报文案 |

## 四、冲突检测规则说明

| 规则ID | 触发条件 | 示例 | 下游展示建议 |
| :--- | :--- | :--- | :--- |
| **规则A** | AI评级≤Ⅱ级 且 历史评级=Ⅳ级 | AI=Ⅰ级，历史=Ⅳ级 → 触发 | 标注“AI与历史直觉严重背离” |
| **规则B** | AI评级≤Ⅱ级 且 财务评级=Ⅳ级 | AI=Ⅱ级，财务=Ⅳ级 → 触发 | 标注“AI与财务直觉严重背离” |
| **规则C** | AI=Ⅰ级 且 历史≥Ⅲ级 且 财务≥Ⅲ级 | AI=Ⅰ级，历史=Ⅳ级，财务=Ⅲ级 → 触发 | 标注“极度异常，建议人工复核” |

## 五、自动复核逻辑说明

当冲突被触发时，系统执行以下归因流程：

1. **历史回撤归因**（比值法）：
   - `个股跌幅 / 大盘跌幅 < 1.2` → 系统性熊市 → 建议下调
   - `1.2 ≤ 比值 ≤ 1.8` → 混合因素 → 建议维持原判
   - `比值 > 1.8` → 个股暴雷 → 建议维持原判

2. **财务杠杆归因**（结构法）：
   - 应付账款占比高 → 供应链占款（良性）→ 建议下调
   - 长期借款占比高 → 主动举债（恶性）→ 建议维持原判
   - 负债率持续下降 → 去杠杆 → 建议下调

3. **综合裁决**：
   - 只有**两个维度均建议下调**时，系统才执行降级
   - 任一维度建议“维持原判”，则维持原等级
