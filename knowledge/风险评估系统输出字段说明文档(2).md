> **更新日期**: 2026-08-07  
> **版本**: v2.0（重大架构升级）

## 一、文件概述

本 JSON 文件由 `riskSystem.py` 风险评估系统针对**单只股票**生成，基于 **模型预测 预测 + 蒙特卡洛模拟 + 财务硬约束 + 历史波动率参考** 的四维融合架构，包含以下核心部分：

- **执行层**：最终风控指令（等级、处置动作）
- **研究层**：归因明细（模型预测/财务/历史三方输入、加权融合过程、蒙特卡洛尾部风险）
- **否决层**：硬否决触发记录（蒙特卡洛动态阈值否决、财务保底否决）
- **RAG 摘要层**：自然语言摘要（供下游检索增强生成）

> **v2.0 核心升级**：
> - 评级逻辑从**静态硬阈值查表**升级为 **模型预测（50%）+ 财务（30%）+ 历史波动率（20%）加权融合**
> - 硬否决从**历史最大回撤**（静态 50%）升级为**蒙特卡洛动态阈值**（基于个股自身预测波动率）
> - 历史最大回撤**完全移出决策层**，仅作为研究层展示参考

## 三、核心字段详解

### 3.1 执行层（直接用于生成风控指令）

| 字段 | 示例值 | 说明 | v2.0变化 |
| :--- | :--- | :--- | :--- |
| `final_level` | `"Ⅲ级"` | 最终等级。下游根据此值映射颜色：Ⅰ级（绿色）、Ⅱ级（黄色）、Ⅲ级（橙色）、Ⅳ级（红色） | 由加权融合+否决项共同决定 |
| `action` | `"【警戒】暂停新开仓..."` | 此文本直接显示在报告“处置建议”栏，必须原样展示，不可修改 | — |
| `verdict_status` | `"已终裁（无冲突）"` | 若为 `"已终裁（自动复核确认）"` 表示经过复核；若为 `"已终裁（无冲突）"` 表示三方一致 | — |
| `dominant_source` | `"模型预测"` 或 `"蒙特卡洛否决"` 或 `"财务否决"` | **决策来源**，表示最终等级的主导因素。v2.0语义从“输入最高等级”改为“决策贡献最大者” | ⚠️ **语义变更** |
| `veto_reason` | `"蒙特卡洛预测极端尾部风险..."` | 若触发硬否决，展示具体原因；否则为 `null` | 🆕 **新增** |
| `mc_veto_triggered` | `false` | 是否因蒙特卡洛预测触发硬否决 | 🆕 **新增** |


### 3.2 模型预测预测层（从上游B模块继承的原始值）

| 字段 | 示例值 | 说明 |
| :--- | :--- | :--- |
| `模型预测_score` | 39.9 | LSTM模型的综合风险评分（0~100分），<40分为低风险区间 |
| `模型预测_L1` | 11.1 | 时序预测层贡献（波动率/Beta等），满分35 |
| `模型预测_L2` | 16.2 | 基本面层贡献（负债率/ROE等），满分35 |
| `模型预测_L3` | 12.5 | 环境上下文层贡献（行业系统性风险），满分25 |
| `pred_vol_pct` | 30.1 | 模型预测的未来1日年化波动率（%） |
| `pred_beta` | -0.219 | 相对于沪深300的60日滚动Beta |


### 3.3 蒙特卡洛尾部风险层（🆕 v2.0全新引入）

| 字段 | 示例值 | 说明 |
| :--- | :--- | :--- |
| `mc_q1_1d_pct` | -4.36 | **蒙特卡洛1%极端亏损分位数**：1000条未来路径中，最差的1%路径的平均亏损（%） |
| `mc_q5_1d_pct` | -2.98 | **蒙特卡洛5%极端亏损分位数**：最差的5%路径的平均亏损（%） |
| `mc_q10_1d_pct` | -2.25 | **蒙特卡洛10%极端亏损分位数**：最差的10%路径的平均亏损（%） |
| `dynamic_threshold_pct` | -4.42 | **动态硬否决阈值**：基于该股票自身预测波动率计算，公式为 `-2.33 × pred_vol / √252`。若 `q1 < 动态阈值`，触发硬否决 |

**动态阈值原理**：
- 波动率越高的股票，其理论极端亏损阈值越低（更宽松）
- 波动率越低的股票，其理论极端亏损阈值越高（更严格）
- 实现了“一票一议”，尊重每只股票自身的波动基因


### 3.4 历史回溯层（v2.0变为“仅展示”）

| 字段 | 示例值 | 说明 | v2.0变化 |
| :--- | :--- | :--- | :--- |
| `hist_vol_pct` | 29.34 | 过去6年年化波动率（%） | — |
| `max_drawdown_pct` | 60.52 | 历史最大回撤幅度（%） | ⚠️ **已移出决策层** |
| `hist_level` | `"Ⅳ级"` | 历史波动率等级（仅基于波动率，回撤不参与） | ⚠️ **语义变更**：不再包含回撤 |
| `vol_level` | `"Ⅳ级"` | 历史波动率子等级 | 🆕 **新增**（明确展开） |
| `mdd_level` | `"Ⅳ级"` | 历史回撤子等级（仅展示，不参与定级） | 🆕 **新增**（明确展开） |

> **重要说明**：历史最大回撤在 v2.0 中**完全移出决策层**，仅作为研究员参考。即使回撤高达60%，也不会直接导致Ⅳ级。最终等级由加权融合 + 蒙特卡洛否决 + 财务否决决定。

| 字段 | 示例值 | 说明 |

### 3.6 加权融合得分（🆕 v2.0核心）

| 字段 | 示例值 | 说明 |
| :--- | :--- | :--- |
| `composite_score` | 56.2 | 加权融合综合得分，计算公式：`模型预测×50% + 财务×30% + 历史波动率×20%`。映射规则：<30→Ⅰ级，30~55→Ⅱ级，55~75→Ⅲ级，≥75→Ⅳ级 |


### 3.7 冲突检测（v2.0更新）

| 字段 | 示例值 | 说明 | v2.0变化 |
| :--- | :--- | :--- | :--- |
| `conflict_count` | 1 | 检测到的冲突数量 | — |
| `has_conflict` | 1 | 存在冲突时标记为1 | — |

**v2.0 冲突检测规则（已更新）**：

| 规则ID | 触发条件 | 说明 |
| :--- | :--- | :--- |
| **规则1（硬否决生效）** | 蒙特卡洛硬否决触发 且 模型预测等级 ≤ Ⅱ级 | 标记“蒙特卡洛否决覆盖了模型预测判断” |
| **规则2（加权偏离）** | 综合得分 ≥ 75 且 模型预测分数 < 40 | 标记“综合得分远高于模型预测原始分，主要由财务/历史因子拉高” |
| **规则3（模型预测独自乐观）** | 模型预测等级 = Ⅰ级 且 历史波动率 ≥ Ⅲ级 且 财务 ≥ Ⅲ级 | 标记“模型预测极度乐观，但历史与财务双双承压” |


### 3.8 复核层（v2.0 行为变化）

| 字段 | 示例值 | 说明 | v2.0变化 |
| :--- | :--- | :--- | :--- |
| `auto_review_verdict` | `"未触发复核"` | 复核系统裁决结果 | ⚠️ **可能为“未触发复核”** |
| `review_det模型预测l` | `{}`（空对象） | 复核归因证据链 | ⚠️ **可能为空对象** |

**v2.0 复核行为**：
- 自动复核仅在**冲突检测有输出**时触发
- 若当前版本冲突规则下无冲突（如美的仅剩“异常背离”），则不触发自动复核
- `review_det模型预测l` 为 `{}` 时，下游应隐藏“复核证据链”展示模块

本字段是**专为检索增强生成（RAG）系统设计的自然语言文本**，v2.0 内容已全面更新。

| 字段 | 示例值（节选） | 说明 |
| :--- | :--- | :--- |
| `rag_summary` | `"美的集团(000333)在2026-08-07的风险评估为Ⅲ级风险。主要风险来源是模型预测模型预测。该股票历史年化波动率为29.34%（等级Ⅳ级），历史最大回撤为60.52%（等级Ⅳ级）。蒙特卡洛预测：1%概率单日亏损-4.36%，5%概率单日亏损-2.98%。模型预测模型给出39.9分（Ⅰ级），三方评级一致，无冲突。"` | v2.0 摘要包含：<br>• 最终等级与处置建议<br>• 决策来源（模型预测/财务/蒙特卡洛否决）<br>• 蒙特卡洛尾部风险分位数<br>• 历史波动率/回撤（仅参考）<br>• 模型预测评分与冲突状态<br>• **不再提及“硬阈值极端红线”** |


## 四、v2.0 核心决策链路说明

下游在解读报告时，应理解以下决策优先级：

```
┌─────────────────────────────────────────────────────────────┐
│                    v2.0 决策链路                            │
├─────────────────────────────────────────────────────────────┤
│  1. 输入层                                                │
│     ├── 模型预测预测 (50%) → 综合分39.9 → Ⅰ级                   │
│     ├── 财务基本面 (30%) → 62.5分 → Ⅲ级                   │
│     └── 历史波动率 (20%) → 87.5分 → Ⅳ级（仅权重低）       │
│                          ↓                                 │
│  2. 加权融合 → 综合得分56.2 → 初步判定 Ⅱ级                │
│                          ↓                                 │
│  3. 否决层（覆盖融合结果）                                 │
│     ├── 蒙特卡洛动态阈值：q1=-4.36% > -4.42% → 不触发     │
│     └── 财务保底：fin_level=Ⅲ级 → 不触发                  │
│                          ↓                                 │
│  4. 最终输出 → Ⅲ级（由加权融合主导，来源：模型预测）            │
└─────────────────────────────────────────────────────────────┘
```
